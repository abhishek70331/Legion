Industry Challenge

The Problem: Manual NDT Bottlenecks

  • Manual Transcription Errors: Inspectors manually read thickness gauges and write values on paper, leading to typos and transposed digits.
  • Slow Workflow: Stopping the probe to write down 12 distinct location readings per insulator significantly slows down factory throughput.
  • Data Silos & Lost Records: Paper inspection logs are difficult to track, search, audit, and analyze for quality trends.
  • Security & Accountability Risks: Lack of user attribution, unauthorized modifications, and difficulty tracking which shift inspected which workpiece.
💡

Goal: Automate data acquisition directly from the flaw detector into a centralized, auditable cloud database with zero manual typing.

Platform Architecture

The Solution: Legion NDT Digital Suite

🖥️ Web Application Dashboard

Modern React 18 responsive dashboard designed for shop-floor workstations, tablets, and manager offices. Features instant search, multi-field filters, and automated shift tracking.

🔌 Hardware Serial Wedge

Lightweight background automation service interfacing with the Olympus EPOCH 650 flaw detector. Captures thickness and advances locations automatically upon pressing FREEZE.

🔒 Hardened REST API

Node.js & Express backend validating every single database transaction independently. No client-side permission trust, brute-force throttled, and session tracked.

🗄️ Scalable Cloud Database

PostgreSQL relational database with 100% parameterized queries, automated audit trails, and strict data integrity across hundreds of thousands of test records.

Hardware Automation

EPOCH 650 Live Capture Workflow

Complete hands-free data entry directly from the physical testing machine.

Step 1: Test Point Contact

Inspector places transducer probe on Workpiece Location 1 (Loc-1).

Step 2: Physical FREEZE

Inspector presses FREEZE on the EPOCH 650. Hardware wedge reads Gate 1 thickness instantly.

Step 3: Auto-Tab & Unfreeze

Script types thickness into Loc-1, beeps, advances focus via TAB to Loc-2, and unfreezes the machine for the next spot!

⚡

Outcome: Inspecting all 12 points of an insulator takes seconds instead of minutes with zero manual typing errors!

User Experience

Smart Data Entry & Ergonomics

  • 12-Location Grid (Loc-1 to Loc-12): Dedicated fields for ultrasonic thickness readings with real-time Min, Max, and Average metric calculations.
  • Auto-Hyphen Formatting for UID: Typing an alphabet prefix automatically formats with hyphen (e.g., typing A $\rightarrow$ A-101).
  • Auto-Decimal Location Inputs: Entering single digits auto-formats with decimal (e.g., typing 2 $\rightarrow$ 2.45) with focus auto-highlighting.
  • Floating Feedback System: Non-intrusive floating toasts in emerald green (success) and crimson red (error alerts).
Defense in Depth

Security & Role-Based Access Control

👑 Super Administrator

Full universal access. Can manage administrators, configure user permissions, view security audit logs, and manage system policies.

🛡️ Administrator

Delegated supervisory role. Can view records, manage shift reports, and oversee day-to-day inspection workflows.

👷 Regular Operator

Shop-floor inspector. Restricted strictly to workpiece testing, record creation, and permitted shift tracking modules.

🔒

Zero Bypass: Permissions are evaluated in the PostgreSQL database on every API request. Tampering with browser code cannot grant unauthorized access.
